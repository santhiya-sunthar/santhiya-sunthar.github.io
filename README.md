# santhiya-sunthar.github.io

Personal portfolio site for **Santhiya Suntharesan**, B2B Marketing & Analytics Professional, Toronto area.

**Live site:** https://santhiya-sunthar.github.io

## What's here

| File | What it is |
| --- | --- |
| `index.html` | The whole site: content, styles and scripts in one file. GitHub Pages serves it as the home page. |
| `README.md` | This file. Shown on GitHub, not on the site. |
| `favicon.ico`, `favicon.svg`, `favicon-32x32.png` | Browser tab icon (the four-shape graphic). |
| `apple-touch-icon.png` | Icon used when the site is saved to an iPhone or iPad home screen. |

The site is a single static HTML page hosted on GitHub Pages. There's no build step. Whatever is in `index.html` on the `main` branch is what goes live.

## Design

- **Direction:** Bold colour block, with full-width sections and thick ink outlines.
- **Colours:** Cobalt `#1F45C9`, Sunflower `#FFC20E`, Ruby `#C4122F`, Ink `#0B1026`, Paper `#F7F6F0`
- **Type:** Inter Tight for headlines and body text, IBM Plex Mono for labels (both from Google Fonts)

## How to update the site

1. **Make the change.** Edit the copy doc, or ask Claude for a change directly. In a new chat, attach the current `index.html` so it edits the live version, and ask for the full updated file back.
2. **Check the file name.** It must be exactly `index.html`. Rename it if your computer saved it as `index (1).html`.
3. **Upload it.** In this repository, go to **Add file → Upload files** and drag in the new `index.html`. It replaces the old one automatically.
4. **Commit.** Write a short note describing the change, for example "Add resume download button", then click **Commit changes**.
5. **Check it's live.** Wait one to two minutes. A green check under the **Actions** tab means it's published. Hard-refresh the site (⌘ + Option + R in Safari) to see it.

For a small text fix, you can also open `index.html` here, click the pencil icon, edit the text directly and commit.

## Undo a change

Open `index.html`, click **History**, find the version you want and copy its contents back, or upload an older copy of the file. Every commit is saved, so nothing is lost.
